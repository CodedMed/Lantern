# Lantern
Computer-Vision surrounding identifying app, helping disabled through navigation.

steps to run:
1. activate whichever venv u have (shouldnt be in git)
    example --> run "lanternenv\Scripts\activate" in terminal
2. start expo project in the folder package.json is in --> npx expo start
    - navigate to lanternv1 expo project --> cd lanternv1
    
    - if doesnt work, try npx expo start --tunnel instead

control c to stop app
